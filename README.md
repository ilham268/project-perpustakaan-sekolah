# SISTEM PEMINJAMAN BUKU PERPUSTAKAAN (LANTERA)

**LANTERA** merupakan sistem peminjaman buku perpustakaan yang dikembangkan untuk membantu pengelolaan layanan perpustakaan di **SMKN 1 Cerme** agar lebih efektif, terstruktur, dan mudah digunakan.

Proyek ini dibuat sebagai bentuk kontribusi dan pengembangan oleh mahasiswa **PLP Universitas Negeri Surabaya (UNESA)** dalam mendukung digitalisasi layanan perpustakaan sekolah.

> *"Dari mahasiswa UNESA untuk SMKN 1 Cerme — menghadirkan teknologi untuk mendukung pendidikan yang lebih baik."*
